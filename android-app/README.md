# Block Ops для Android

Полноэкранная Android-версия игры на React, Three.js и Capacitor. Игра работает локально внутри приложения и не требует открывать сайт.

## Установка готового APK

1. Скопируйте `output/Block-Ops-Android-debug.apk` на телефон.
2. Разрешите установку приложений из выбранного файлового менеджера.
3. Откройте APK и установите Block Ops.

APK подписан стандартным отладочным ключом Android и подходит для тестирования на телефоне.

## Повторная сборка

```powershell
npm run android:apk
```

Готовый файл снова появится в `output/Block-Ops-Android-debug.apk`.

## Управление

- На телефоне: левый джойстик — движение, правая область — обзор, отдельные кнопки огня, оптики, перезарядки, прыжка и ножа.
- На компьютере/эмуляторе: WASD, мышь, Space — прыжок, Q — AWP/нож, ЛКМ — атака, ПКМ — оптика.
