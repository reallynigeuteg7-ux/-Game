# Block Ops для Android

Конфигурация Android-оболочки на React, Three.js и Capacitor.
Имя приложения — **Block Ops**, идентификатор — `game.blockops.awparena`.

## Текущее состояние

В этой папке сохранены зависимости, настройки Vite / TypeScript,
`index.html` и конфигурация Capacitor. Исходники `src/`, нативный Android-проект,
скрипт `scripts/build-android.ps1` и готовый APK отсутствуют.
Команды сборки сейчас не могут создать работающую игру.

## Сохранённые команды

| Команда | Назначение после восстановления исходников |
| --- | --- |
| `npm run dev` | Запустить Vite |
| `npm run build` | Проверить TypeScript и собрать веб-версию |
| `npm run android:sync` | Собрать веб-версию и синхронизировать Capacitor |
| `npm run android:open` | Открыть нативный Android-проект |
| `npm run android:apk` | Вызвать отсутствующий скрипт сборки APK |

Согласно исходному описанию, сборка называлась
`output/Block-Ops-Android-debug.apk` и использовала отладочную подпись.
Этот файл в репозиторий не включён.

## Управление из исходного описания

- Телефон: левый джойстик — движение, правая область — обзор;
  отдельные кнопки огня, оптики, перезарядки, прыжка и ножа.
- Компьютер / эмулятор: WASD, мышь, Space — прыжок,
  Q — AWP / нож, ЛКМ — атака, ПКМ — оптика.
