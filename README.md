# Block Ops — AWP Arena

**Репозиторий конфигурации мини-проекта 3D-игры для браузера и Android.**

TypeScript · React · Three.js · Vite / vinext · Capacitor

Название **Block Ops — AWP Arena** сохранено в Android-оболочке проекта.
Репозиторий содержит настройки веб-сборки и упаковки через Capacitor.

> **Состояние репозитория:** исходники игровой сцены и готовый APK не включены.
> Из текущего набора файлов игру собрать и запустить нельзя.

## Управление из описания Android-версии

Сохранённое описание предусматривает следующие действия; их реализация
в текущем репозитории отсутствует.

| Платформа | Управление |
| --- | --- |
| Телефон | Левый джойстик — движение, правая область — обзор |
| Телефон | Кнопки огня, оптики, перезарядки, прыжка и ножа |
| Компьютер / эмулятор | WASD и мышь; Space — прыжок |
| Компьютер / эмулятор | Q — AWP / нож, ЛКМ — атака, ПКМ — оптика |

## Что нужно для восстановления

- `app/` — исходники веб-игры, на которые рассчитан корневой шаблон.
- `android-app/src/` — React-код Android-версии; `index.html` ожидает `src/main.tsx`.
- `android-app/scripts/build-android.ps1` — скрипт, указанный в команде `android:apk`.
- Нативная Android-папка Capacitor и ассеты игры, если они были в исходном проекте.

Команды npm сохранены в `package.json`, но полноценная сборка возможна
только после возвращения недостающих исходников.
